# Easy Sweeper

Tired of sweeping being an awful experience of spamming one button? Help your fingers rest with Easy Sweeper.

## Install

### Mod managers

Install Easy Sweeper through [Sailwind Mod Synchronizer](https://github.com/foxyv/SailwindModSynchronizer/releases/latest), r2modman or Thunderstore Mod Manager, then launch Sailwind through your manager. Dependencies are installed automatically.

### Manual installation

1. Install [BepInEx 5](https://github.com/BepInEx/BepInEx/releases) in your Sailwind game folder, following its installation instructions.
2. Download and extract the [Easy Sweeper ZIP](https://github.com/Skeptic043/Sailwind-Easy-Sweeper/releases/latest). Copy its `BepInEx/plugins/EasySweeper` folder into `BepInEx/plugins` in your Sailwind folder.
3. Launch Sailwind normally.

## How it works

While holding a broom, press and hold the use button in order to sweep your boat back to its former glory. No repeated button presses necessary.

## Compatibility

No known incompatibilities.
